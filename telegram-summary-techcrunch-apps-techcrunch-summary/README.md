# Telegram-бот для вечернего дайджеста TechCrunch Apps

Бот раз в день в `19:00` по Москве собирает новые статьи из раздела `Apps` на TechCrunch, делает короткую русскую выжимку, добавляет ссылку на полную статью и отправляет только релевантные изображения из материала в Telegram.

## Что делает бот

- Ищет новые статьи на странице `https://techcrunch.com/category/apps/`
- Для каждой статьи берет:
  - заголовок
  - автора
  - короткую русскую выжимку
  - ссылку на полную статью
  - основную картинку статьи или релевантные изображения из тела статьи
- Раз в день отправляет короткие карточки по статьям с изображениями
- Запоминает уже отправленные URL, чтобы не дублировать статьи
- По умолчанию отправляет не больше `3` новых статей за один запуск

## Подготовка

1. Убедитесь, что установлен Python `3.11+`
2. Создайте Telegram-бота через `@BotFather`
3. Узнайте `chat_id` канала, группы или личного чата
4. Скопируйте `.env.example` в свой `.env` или просто экспортируйте переменные окружения

## Переменные окружения

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота
- `TELEGRAM_CHAT_ID` — id чата, группы или канала
- `MAX_ARTICLES_PER_RUN` — сколько новых статей отправлять за один запуск, по умолчанию `3`
- `SSL_CERT_FILE` — путь к файлу корневых сертификатов, если в системе есть проблема с SSL
- `TECHCRUNCH_ALLOW_INSECURE_SSL=1` — резервный режим, только если SSL не удается настроить нормально

## Локальный запуск

Ручной тестовый запуск:

```bash
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
export MAX_ARTICLES_PER_RUN="3"
python3 bot.py --run-once
```

Запуск в режиме ожидания ежедневной отправки:

```bash
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
export MAX_ARTICLES_PER_RUN="3"
python3 bot.py
```

После запуска бот сам дождется `19:00` по часовому поясу `Europe/Moscow`.

## Хранение состояния

Список уже отправленных статей хранится в файле `work/state.json`.

## Запуск через GitHub Actions

В проект уже добавлен workflow:

- [.github/workflows/digest.yml](/Users/andyukin/Documents/Codex/2026-07-28/telegram-summary-techcrunch-apps-techcrunch-summary/.github/workflows/digest.yml)

Что нужно сделать в GitHub:

1. Залить проект в репозиторий GitHub
2. Открыть `Settings` -> `Secrets and variables` -> `Actions`
3. Добавить секреты:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Открыть вкладку `Actions` и вручную запустить workflow `TechCrunch Apps Digest` для первого теста

Что делает workflow:

- запускается каждый день в `19:00` по `Europe/Moscow`
- поддерживает ручной запуск через `workflow_dispatch`
- запускает `python3 bot.py --run-once`
- сохраняет обновленный `work/state.json` обратно в репозиторий, чтобы бот не отправлял старые статьи повторно
- если нужно, количество статей можно ограничить через `MAX_ARTICLES_PER_RUN`

Важно:

- у workflow должны быть права на запись в репозиторий, потому что он коммитит `work/state.json`
- если репозиторий приватный, это обычно работает из коробки с `GITHUB_TOKEN`
- если в репозитории отключены права записи для Actions, нужно включить `Read and write permissions` в настройках Actions

## Ограничения текущего MVP

- Короткий русский текст строится без полноценного редакторского переписывания, поэтому местами может звучать чуть механически
- Верстка TechCrunch может меняться, поэтому парсер со временем может потребовать обновления
- В некоторых статьях TechCrunch есть только одна основная картинка, и тогда бот отправит только ее
